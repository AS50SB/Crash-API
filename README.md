# Crash-API
A Python lib to crash your program.  
# Never on pip!!!  
**Functions:**  
*crash()*  
**parameters**:
 - crash_title [str] Your custom crash title(Default:Unknow Error)
 - description [str] Your custom crash description(Default:Unknow error.)
 - report [bool] Whether to generate a crash report(Default:False)\
    - File:Crash-Report-%Y-%m-%d-%H-%M-%S.txt
 - report_message [str] Your custom crash report info(Default:This report is unknow.)
 - close [bool] Whether to close the program
 - box [bool] Whether to show error messagebox
**depends**:
 - tkinter.messagebox
 - datetime
